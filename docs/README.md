## Convenções

- `RF`: requisito funcional.
- `RNF`: requisito não funcional.
- `RN`: regra de negócio.
- `ADMIN`: administrador com acesso global.
- `BARBEIRO`: profissional com acesso operacional restrito.

Os diagramas usam Mermaid e são renderizados diretamente pelo GitHub.
